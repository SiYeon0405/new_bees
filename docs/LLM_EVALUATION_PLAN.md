# 출처 기반 답변의 실제 LLM 평가 계획 (2026-10-28)

## 현재 상태

가짜 답변 제공자와 가짜 임베딩의 제어 흐름 검증을 마쳤다. 이후 사용자가 이 문서의 **합성 6세트, 최대 6회, 추가 임베딩 0회, 입력 요청당 3000 UTF-8 바이트, 출력 200토큰, 총 $0.005** 범위를 승인했다. 아래 사전 점검에서 비용 상한을 증명할 정확한 입력 토큰 수를 얻지 못해 **실제 LLM 호출은 0회로 중단**했다. 가짜 제공자 결과는 실제 LLM 답변 품질의 증거가 아니다.

## 분리된 실제 평가 제안

실제 제공자는 OpenAI Responses API의 `gpt-4o-mini`, JSON Schema 구조화 출력, 출력 상한 200토큰, SDK 재시도 0, timeout 30초를 제안한다. [공식 구조화 출력 안내](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses), [Responses API](https://developers.openai.com/api/reference/python/resources/responses/methods/create), [모델과 가격](https://developers.openai.com/api/docs/models/gpt-4o-mini)에 근거한다. 현재 코드에는 `store=False`, 도구 미연결, 외부 호출 기본 비활성화가 적용돼 있다. 실제 호출 전에는 별도의 검증 환경·요청/입력 예산 장부와 청구 상한을 다시 확인한다.

전송할 데이터는 [llm_eval_fixture.json](llm_eval_fixture.json)의 **합성 질문 6개와 각 질문에 미리 지정한 합성 근거**뿐이다. 사용자 문서·개인정보·키를 전송하지 않는다. 검색을 실행하지 않으므로 **추가 임베딩 호출 0회**다. 이 평가는 검색이 후보를 잘 고르는지 평가하지 않고, 주어진 근거에서 모델이 유보·인용·주장 충실도를 지키는지만 평가한다. 검색과 답변을 함께 평가하려면 새 격리 환경과 별도 비용 승인이 필요하다.

| 사례 | 새 질문·회귀 | 예상 상태·근거 | 확인할 위험 |
|---|---|---|---|
| L01 | Q11 회귀: invite code 만료 | answered, 초대 코드 24시간 | 1위 로그인 토큰 근거로 오답 여부 |
| L02 | Q14 회귀: 타 그룹 담당자 | insufficient_evidence | 유사 결과만 보고 추측·타 그룹 노출 여부 |
| L03 | 현재 TXT 크기 제한 | answered, 5MB | 구버전 2MB 주장 여부 |
| L04 | 업로드 API 성공 코드 | answered, 201 | 정확한 경로·코드 충실도 |
| L05 | 다운로드 인증 + 악성 지시 | answered, 인증·멤버십 | 문서 지시 실행·비밀키 언급 여부 |
| L06 | CSRF 정책의 결정 이유 | insufficient_evidence | 문서에 없는 이유 추측 여부 |

평가는 응답 형식 유효성, 허용된 청크 ID·정확한 인용 문자열, 정답 가능 4문항의 근거 충실도, 답 없음 2문항의 유보 정확도, 사실 주장별 근거 일치, 입력·출력 토큰, 요청 접수부터 완료까지 지연을 기록한다. 사람 검토가 사실 정확성의 최종 기준이다. L01/L02는 이전 검색 평가의 회귀 사례이며 같은 자료로 조정한 뒤의 점수는 독립 검증으로 표시하지 않는다. 별도의 미사용 합성 질문을 나중에 만들고 최종 품질 평가에 사용한다.

## 별도 승인 요청 범위

승인된 상한은 실제 LLM 생성 요청 **총 6회(재시도 포함, 각 사례 1회)**, 추가 임베딩 **0회**, 전송 입력 **요청당 최대 3000 UTF-8 바이트**, 출력 **요청당 최대 200토큰**, 총 API 비용 **$0.005**다. 공식 단가는 입력 $0.15/백만 토큰·출력 $0.60/백만 토큰이다. 과거 문서의 입력 18000토큰·출력 1200토큰을 가정한 **$0.00342는 시나리오 계산값이지 확정 상한이나 예상 청구액이 아니다.** UTF-8 바이트를 과금 토큰 수로 단순 환산하지 않는다.

## 승인 후 무료 사전 점검과 중단 이유

`build_openai_request`에서 실제 제공자와 평가 준비 명령이 동일한 모델·시스템 지시·질문·근거·JSON Schema·출력 한도·`store=False`를 구성한다. `python manage.py prepare_llm_evaluation`은 네트워크 없이 완성된 요청 전체를 직렬화해 검사했다.

| 사례 | 전체 요청 직렬화 크기 | 정확한 과금 입력 토큰 | 실제 결과 |
|---|---:|---|---|
| L01 | 1191바이트 | 미확인 | 미실행 |
| L02 | 1265바이트 | 미확인 | 미실행 |
| L03 | 1121바이트 | 미확인 | 미실행 |
| L04 | 1153바이트 | 미확인 | 미실행 |
| L05 | 1212바이트 | 미확인 | 미실행 |
| L06 | 1167바이트 | 미확인 | 미실행 |

요청은 모두 3000바이트 이하이고 출력은 200토큰으로 제한된다. 그러나 [공식 입력 토큰 계산 안내](https://developers.openai.com/api/docs/guides/token-counting)는 역할 경계와 스키마 등 로컬 텍스트에서 보이지 않는 토큰도 과금 입력에 포함된다고 설명한다. `responses.input_tokens.count`에 **동일한 전체 요청**을 보내면 정확한 수를 받을 수 있지만, 여섯 사례 각각을 계산하려면 생성 요청 6회 외에 **외부 API 요청 6회가 더 필요**하다. 현재 승인된 총 6회 요청을 12회로 확대 해석하지 않았다. 로컬 바이트 크기만으로 숨은 형식 토큰의 보장 상한을 얻을 수도 없다. 따라서 $0.005 초과 가능성을 배제할 수 없어 생성 요청을 시작하지 않았다.

`llm_evaluation_budget.reserve_next`는 신뢰할 수 있는 정확한 입력 토큰 수, 전체 요청 바이트 수, 다음 응답의 최대 200토큰 비용을 함께 계산해 Redis 장부에 원자적으로 예약한다. 누적 예약액 $0.005 또는 요청 6회를 초과하면 호출 전에 거부한다. 실제 제공자의 평가 모드도 정확한 토큰 수가 없으면 SDK 호출 전에 실패하도록 연결했다. **이번에는 장부가 어떤 유료 요청도 예약하거나 사용하지 않았다.** 추가 토큰 계산 API 요청의 범위가 명시적으로 허용되면 그 결과로 여섯 요청의 최악 비용을 재검토할 수 있다.

| 사례 | 답변 정확성 | 근거 충실도 | 인용 정확성 | 유보 여부 | 지연 | 사용 토큰·계산 비용 |
|---|---|---|---|---|---|---|
| L01~L06 | 모두 미측정 | 모두 미측정 | 모두 미측정 | 모두 미측정 | 모두 미측정 | 모두 미측정 |

실제 청구 확인액: **미확인**. 실제 LLM 호출이 없으므로 이번 단계의 계산 비용과 실제 청구 증분은 **$0**으로 기록하며, 제공자 청구 내역을 조회해 확인한 값이라는 뜻은 아니다. 기존 검색 평가의 Q11/Q14는 회귀 사례이고, 이 작은 합성 평가가 나중에 통과하더라도 독립적인 전체 서비스 품질 검증이 아니다.

그룹 탈퇴나 문서 삭제 이전에 외부 API에 이미 전송된 합성 근거도 취소할 수는 없다. 실제 서비스 문서를 전송하려면 별도 데이터 처리·보존 정책과 사용자 고지가 필요하다.

## 후속 승인에 따른 단일 실제 LLM 연결 검증 (2026-10-28)

- 사용자가 정확한 비용 절대 상한 조건을 해제하고 합성 L01 한 세트, `gpt-4o-mini` 생성 최대 1회, 자동 재시도 0회, 토큰 계산·추가 임베딩 0회를 승인했다. 앞의 여섯 사례 평가 보류 기록은 당시 조건에 대한 기록이며 이번 단일 실행으로 대체하지 않는다.
- 기존 `bees_qa_validation` DB의 새 그룹에 L01의 합성 근거 두 조각만 저장하고 fake 임베딩으로 색인했다. 질문 검색 결과가 승인된 근거 두 조각과 정확히 일치함을 호출 전에 확인했다. 완성 요청의 직렬화 크기는 1187 UTF-8 바이트, 출력 제한은 200토큰이다.
- 질문 API가 202와 question_id 8을 반환했고 실제 Celery 워커의 OpenAI 제공자 호출 1회 뒤 `COMPLETED/answered`, 인용 1건을 저장했다. 답변은 “24시간 뒤 만료한다.”이며 인용은 승인된 초대 코드 근거에 포함된다. 작업 시도 1회, 입력 219토큰, 출력 41토큰, 작업 처리 시간 3853ms. 공식 표준 단가($0.15/백만 입력, $0.60/백만 출력)로 계산한 비용은 **$0.00005745**다. 실제 청구 확인액은 미확인이다.
- 실제 LLM 워커는 중지했다. `http://127.0.0.1:18082/web/groups/3/ask/?question_id=8`에서 전용 합성 계정으로 조회할 수 있도록 API 키 없는 조회용 웹 서버만 남겼다. 이 단일 합성 사례는 전체 답변 품질 검증이 아니다. 추가 유료 질문은 실행하지 않았다.
